# 圆明园 · 万园之园

用浏览器打开的圆明园三维数字游览。场景全部由代码现场搭出来，不依赖外部模型文件。

这是**意象性复原**，用来感受园林格局与西洋楼残迹，不是按考古测绘做的精确重建。

## 怎么打开

页面用了浏览器模块加载三维库，需要通过本地网页服务打开，直接双击 `index.html` 通常无法正常运行。

在项目目录执行：

```bash
python3 -m http.server 8080
```

然后在浏览器访问 [http://localhost:8080](http://localhost:8080)。

## 能看到什么

园子分成两块：

- **中式园林**：大宫门、出入贤良门、正大光明殿、九州清晏、福海、蓬岛瑶台、曲院风荷、石拱桥与画舫。
- **西洋楼**：谐奇趣、万花阵、海晏堂（十二生肖报时水法）、观水法、大水法、远瀛观、线法山。西洋楼以残柱、碎石的状态呈现。

右侧「游览」列表可以飞到对应景点。点击殿宇、桥梁、喷泉等物体，左下角会显示名称和简短说明。

## 怎么操作

| 操作 | 作用 |
| --- | --- |
| 拖拽 | 旋转视角 |
| 滚轮 | 拉近 / 拉远 |
| 右键拖拽 | 平移 |
| 点击建筑 | 查看介绍 |
| 时辰滑杆 | 从子夜到白昼再到入夜，天空、阳光和雾会跟着变 |
| 自动流转 | 时间自己往前走 |
| 自动巡游 | 按景点列表依次飞过去，大约每 15 秒换一处 |
| 宫灯夜明 | 夜里是否点亮宫灯 |
| 烟岚 | 是否显示雾气 |

窄屏时右侧控制面板会隐藏，仍可以用鼠标或触控在场景里转动、缩放。

## 技术说明

整个项目只有一个 `index.html`，没有打包步骤，也没有需要安装的依赖。

- [Three.js](https://threejs.org/) `0.160.0`：场景、相机、灯光与建筑几何，通过 CDN 引入。
- 轨道控制来自 Three.js 的 `OrbitControls`。
- 样式使用 [Tailwind CSS](https://tailwindcss.com/) 浏览器版。

贴图（琉璃瓦、石材、窗棂、彩画、水面）在页面加载时用画布画出来。树木、假山、宫墙和西洋楼残迹也是程序生成的几何体。加载画面会按「备料、挖湖、营殿」的顺序分步搭建场景。
